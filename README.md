# 🌍 국내 여행 추천 LLM 에이전트

한국 국내 여행 코스를 추천해주는 고급 LLM 에이전트입니다. 사용자의 선호도, 기간, 인원을 고려하여 맞춤형 여행 계획을 제시합니다.

## 🎯 주요 기능

### 1. **스마트 지역 및 테마 선택**
- 7개 주요 지역 지원 (서울, 부산, 경주, 제주, 강릉, 대구, 전주)
- 10가지 여행 테마 (문화, 해변, 먹거리, 자연, 쇼핑, 휴양, 액티비티, 야경, 불교, 차)

### 2. **LLM 기반 맞춤 추천**
- OpenAI GPT-4o-mini를 활용한 지능형 여행 코스 추천
- 사용자의 취향 및 조건을 고려한 3가지 추천 안
- 각 코스별 상세 설명 및 추천 이유 제공

### 3. **정확한 비용 계산**
- 교통비 (지역별 상이)
- 식사 및 관광비 (일별)
- 숙박비 (박수 기반)

### 4. **사용자 친화적 인터페이스**
- 단계별 입력 수집
- 추천 결과 시각화
- 코스 선택 및 최종 계획 수립
- 실시간 비용 계산

## 📋 여행 데이터

### 지원 지역
- **서울**: 문화, 쇼핑, 야경 코스
- **부산**: 해변, 먹거리, 문화 코스
- **경주**: 신라문화, 불교 코스
- **제주**: 자연, 휴양, 액티비티 코스
- **강릉**: 해변, 차 문화 코스
- **대구**: 문화, 먹거리 코스
- **전주**: 한옥마을, 음식문화 코스

### 여행 테마
| 테마 | 설명 |
|------|------|
| 문화 | 역사적 유산과 전통문화를 체험하는 여행 |
| 해변 | 해변에서 휴양하며 자연을 즐기는 여행 |
| 먹거리 | 지역의 특색있는 음식을 맛보는 여행 |
| 자연 | 산, 숲, 자연경관을 감상하는 여행 |
| 쇼핑 | 쇼핑과 도시문화를 즐기는 여행 |
| 휴양 | 조용한 휴양지에서 쉬는 여행 |
| 액티비티 | 스포츠와 레저 활동을 하는 여행 |
| 야경 | 도시의 야경과 야간문화를 즐기는 여행 |
| 불교 | 불교유산을 둘러보는 영적인 여행 |
| 차 | 차 문화를 체험하는 여행 |

## 🚀 사용 방법

### 1. 환경 설정
```bash
# .env 파일 생성 및 OpenAI API 키 설정
echo "OPENAI_API_KEY=your_api_key_here" > .env
```

### 2. 프로그램 실행
```bash
python main.py
```

### 3. 상호작용
프로그램 시작 후 다음 순서로 진행됩니다:

1. **지역 선택**: 1-7 중 숫자 입력
2. **여행 기간**: 1-7일 중 선택
3. **인원 수**: 1-10명 중 선택
4. **테마 선택**: 1-10 중 선택
5. **추천 결과**: 3가지 코스 추천 확인
6. **비용 검토**: 상세 비용 확인
7. **코스 선택**: 최종 코스 선택

## 📊 예시: 부산 여행 계획

**입력:**
- 지역: 부산
- 기간: 3일
- 인원: 4명
- 테마: 먹거리

**추천 결과:**
1. 부산 해산물 투어
2. 부산 해변 여행
3. 부산 문화유산 투어

**비용 계산 (해산물 투어 선택 시):**
```
- 교통비 (왕복): ₩60,000
- 식사 및 관광 (3일): ₩135,000
- 숙박비 (2박): ₩120,000
- 소계: ₩315,000/인
- 단체할인 (15%): -₩47,250/인
- 최종: ₩267,750/인
- 전체 (4명): ₩1,071,000
```

### 2. LLM 호출

- JSON 형식 응답 처리
- 폴백 메커니즘 내장

### 3. 비용 계산 알고리즘
```python
총비용 = (교통비 × 2 + 일일비용 × 기간 + 숙박비) × 할인율 × 인원수
할인율 = PEOPLE_DISCOUNT_RATE[인원수]
```
